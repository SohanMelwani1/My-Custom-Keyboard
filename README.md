# My-Custom-Keyboard
My own Custom 60% Mechanical Keyboard

# Features
- 3 Macros
- Anti-Ghosting
- customizable keycaps and switches
- swappable switches without needing to re-solder it
- 60% mechanical keyboard
- no screws required
- 3d printed case
- Matrix layout
- 61 keys
